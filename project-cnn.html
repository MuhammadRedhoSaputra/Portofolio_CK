Model Klasifikasi MobileNetV2

Pelatihan model klasifikasi penyakit daun cabai dengan CNN arsitektur MobileNetV2 di Google Colab.

Tentang Proyek

Tahap awal proyek adalah membuat model klasifikasi citra dengan arsitektur MobileNetV2 yang dilatih menggunakan dataset gambar daun cabai dari berbagai jenis penyakit. Setelah model selesai dilatih, model dipakai dalam API Flask dan antarmuka Laravel agar pengguna dapat mengunggah gambar dan menerima hasil klasifikasi.
